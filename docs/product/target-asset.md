# DA-01 目标资产摘要（Target Asset Summary）

> 完整蓝图：Infinity_AI_Project/plan/plan_ai/DA01_TARGET_ASSET.md（私有规划仓库，不随本仓库公开）。
> 本文件只保留可公开的定位、功能清单与版本里程碑摘要。

## 一句话定义

**WorkPilot：一个可私有部署的「研发工作 AI 助手平台」——把团队/个人的研发知识（文档、规范、代码仓库、Issue、运行手册）接入，用带引用的 RAG 回答问题，用可审批的 Agent 调用工具完成高频研发工作流（调研、需求拆解、评审、排障、周报），并通过 MCP 直接嵌入 IDE；自带评测、可观测、安全护栏和一键部署。**

## 功能清单（v2.0 交付形态）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 知识空间（Workspace & Knowledge Base） | 多工作空间、数据接入、自动处理、文档管理 |
| F2 | 知识问答（Grounded Q&A） | 流式回答 + 段落级引用、知识不足拒答、反馈闭环 |
| F3 | Agent 任务中心（Agent Runs） | 内置任务、步骤时间线、写操作人工审批、可中断恢复 |
| F4 | IDE 集成（MCP） | MCP Server 嵌入 IDE，兼作 MCP Client 接外部工具 |
| F5 | 评测中心（Eval Center） | 数据集管理、一键评测、版本对比、回归门禁、Badcase 库 |
| F6 | 运维看板（Ops） | 延迟/成本/错误率、预算降级、Trace 查看 |
| F7 | 安全与权限 | JWT、角色、空间隔离、Prompt Injection 防护、脱敏、审计 |
| F8 | 交付与运维 | compose 一键部署、备份恢复、完整文档 |
